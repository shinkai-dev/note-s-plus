# Note S+

ブラウザだけで使える、ローカル保存型のMarkdownメモ帳です。

クラウドやローカルファイルを使わず、ブラウザ内のデータベース（IndexedDB）にメモを保存します。ファイルやアカウントを作らず、仕事中の調査メモや個人的なちょっとした記録など、手元に残しておきたい情報を気軽に書き留められます。

> 「ファイルにするほどではない。でも、いつものフォルダやクラウドには置きたくない。」そんな情報を、ブラウザの中にさっと残すためのメモ帳です。

## 特徴

- **HTMLファイル1つで動作** — CSS・JavaScriptを内包した単一ファイル構成。ダウンロードしてブラウザで開くだけで使えます。
- **ブラウザ内に保存** — ノートはIndexedDBに保存。通常の文書ファイルとしてフォルダに作成されません。
- **オフライン利用** — 外部ライブラリ、CDN、APIへの依存はありません。アプリ自体はネット接続なしで利用できます。
- **Markdown編集** — 編集しながらプレビューを確認でき、編集・分割・プレビューの3つの表示モードを切り替えられます。
- **ノート管理** — 全文検索、タグ、ピン留め、並び替え、ドラッグによる手動並び替えに対応。
- **履歴と復元** — バージョン履歴の自動保存、スナップショット、ゴミ箱からの復元に対応。
- **バックアップと書き出し** — JSONバックアップ、Markdown・テキスト・HTML形式の書き出し、CSV形式での一覧出力に対応。
- **使い方に合わせた調整** — 4種類のテーマ、フォント、文字サイズ、行間、本文幅を設定できます。
- **キーボード操作** — コマンドパレットや各種ショートカットから操作できます。

## はじめかた

1. [`Note-S-Plus.html`](./Note-S-Plus.html) をダウンロードします。
2. ダウンロードしたHTMLファイルを、対応ブラウザで開きます。
3. 左側の「＋ 新規メモ」からノートを作成し、本文を書き始めます。

入力した内容は自動的にブラウザ内へ保存されます。インストールやアカウント登録は不要です。

### 保存先について

ノートや設定などのデータは、利用しているブラウザのIndexedDBに保存されます。通常のファイルとしてドキュメントフォルダなどに作成されるわけではありません。

保存データはブラウザやプロファイルごとに管理されます。別のブラウザや別のPCへ自動同期する機能はありません。

## 主な機能

### Markdownエディタ

- Markdownのライブプレビュー
- 編集・分割・プレビューの3モード
- 見出し、太字、斜体、取り消し線、ハイライト
- 箇条書き、番号付きリスト、タスクリスト
- 引用、コードブロック、表、リンク
- コードブロックの言語ラベルとコピー操作
- タスクリストをプレビュー上で操作
- ノート内検索・置換
- リスト入力の自動継続やインデント操作

### ノート管理

- ノートの新規作成・複製
- 全文検索
- タグ付けとタグによる絞り込み
- ピン留め
- 更新日時などによる並び替え
- ドラッグによる手動並び替え
- 検索条件や表示条件を保存するビュー
- ゴミ箱への移動と復元
- ゴミ箱内のノートは30日経過後に自動削除
- 複数ノートの一括操作

### 履歴・バックアップ

- ノートのバージョン履歴（10分ごとの自動保存、最大25世代）
- 任意のスナップショット保存
- JSON形式で全ノートをバックアップ
- JSONバックアップを貼り付けて復元・マージ
- ノート単位でMarkdown・テキスト・HTMLを書き出し
- ノート一覧をCSVで書き出し（BOM付き）
- 変更が一定数たまった際のバックアップ案内

### 表示・操作

- ライトモード
- ダークモード
- ダークモード（グラファイト）
- ダークモード（ライム）
- 本文フォントの切り替え（ゴシック・明朝・等幅）
- 文字サイズ、行間、本文の最大幅の調整
- 分割表示時のスクロール同期
- 集中モード
- コマンドパレット

## キーボードショートカット

| 操作 | ショートカット |
|---|---|
| コマンドパレット | `Ctrl + K` / `⌘ + K` |
| 今すぐ保存 | `Ctrl + S` / `⌘ + S` |
| 新規メモ | `Alt + N` |
| メモ内検索・置換 | `Ctrl + F` / `⌘ + F` |
| サイドバー検索 | `/` |
| 太字 | `Ctrl + B` / `⌘ + B` |
| 斜体 | `Ctrl + I` / `⌘ + I` |
| 取り消し線 | `Ctrl + Shift + X` / `⌘ + Shift + X` |
| 書き出しメニュー | `Ctrl + Shift + E` / `⌘ + Shift + E` |
| 表示モード切替 | `Ctrl + \\` / `⌘ + \\` |
| インデント / 解除 | `Tab` / `Shift + Tab` |
| リストの自動継続 | `Enter` |
| 閉じる・集中モード解除 | `Esc` |

※ `Ctrl` / `⌘` は、利用するOSに応じた修飾キーです。

## データのバックアップと全消去

### バックアップ

設定画面の「データ」から、全ノートをJSON形式でバックアップできます。復元するときは、バックアップJSONの内容をテキストとして貼り付けます。

ブラウザのストレージは、ブラウザの設定やプライベートブラウジング、利用環境のクリーンアップなどによって消去される場合があります。大切なノートは定期的にバックアップしてください。

### 全データの削除

設定画面の「データ」から全データを削除できます。実行前に確認ダイアログが表示され、確認後にノート（ゴミ箱内を含む）、バージョン履歴、保存ビュー、設定、バックアップ情報を削除します。この操作は取り消せません。必要なデータは、事前にJSONバックアップを取得してください。

## プライバシーと注意事項

- Note S+ はノートをブラウザのIndexedDBに保存し、アプリから外部サーバーへ送信しません。
- アカウント登録やクラウド同期はありません。
- IndexedDBに保存されたデータは、暗号化やアクセス制限によって保護されるものではありません。
- 同じブラウザプロファイルを利用できる人や、端末自体にアクセスできる人から、データを守る機能はありません。
- ファイル一覧から見つけにくい保存方式ですが、秘密情報を安全に隠すための仕組みではありません。
- パスワード、認証情報、顧客情報、機密情報などの保管には使用しないでください。仕事で利用する場合は、所属組織の情報管理ルールに従ってください。
- ブラウザのストレージが利用できない場合、画面上に警告が表示されます。その状態では内容がタブを閉じた後に保持されない可能性があります。

## 動作環境について

IndexedDBに対応した最新のデスクトップブラウザでの利用を想定しています。HTMLファイルを直接開く方法では、ブラウザによってローカルファイルの保存動作が異なる場合があります。保存に関する警告が表示された場合は、別のブラウザで試すか、利用環境の設定を確認してください。
